#### What is WCM? 
WCM is a **computer vision**, Weapon Classification Model. The first version of the model can classify the following: 
- Handweapons (Pistols, Knives, Swords, Grenades, Missiles)
- Snipers 
- Rifles 

#### Why am I building a WCM? 

Recent events within my country inspired me to create this. It made me think "How can I aid to the contribution of security within my country?"

Most universities, malls are running their securities through CCTVs and once there is an alert/report, they will take action. But the question lies more on, how can we take action right away before the event happens?
